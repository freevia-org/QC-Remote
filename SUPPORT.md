# Getting help with QC Remote

QC Remote is an independent, unofficial controller for the Neural DSP Quad
Cortex. It is not affiliated with, endorsed by, or supported by Neural DSP
Technologies Oy, and Neural DSP support does not cover it. See
[`TRADEMARKS.md`](TRADEMARKS.md).

QC Remote is published by Freevia. Support is provided on a
best-effort basis: no response time, fix date, or compatibility with any
particular firmware version is promised.

## Start with the user guide

The [user guide](docs/USER-GUIDE.md) covers connecting a Quad Cortex over USB,
what the connection indicators mean, access levels and safety checks, connecting
an AI assistant, and a
[troubleshooting](docs/USER-GUIDE.md#troubleshooting) section for the most
common problems. Changes in each release are listed in
[`CHANGELOG.md`](CHANGELOG.md).

## Where to ask what

| You want to... | Go to |
| --- | --- |
| Report a bug in QC Remote | Open an issue with the **Bug report** form on the [issues page](https://github.com/freevia-org/QC-Remote/issues/new/choose). The form lists what to include and what not to share. In the Windows app, **Help > Report an Issue...** opens it with the version and a redacted diagnostics summary filled in. |
| Suggest an improvement | Open an issue with the **Feature request** form, from the same page. |
| Report a security problem | Do not open a public issue. Follow [`SECURITY.md`](SECURITY.md). |
| Ask about privacy or what the optional relay stores | Read [`PRIVACY.md`](PRIVACY.md), also published at <https://freevia.org/qcremote/privacy>. |
| Ask about the Quad Cortex itself, its firmware, or Neural DSP's own software | Contact [Neural DSP support](https://support.neuraldsp.com/help/). QC Remote cannot help with the unit itself. |
| Ask about licensing or trademarks | Read [`LICENSE`](LICENSE) and [`TRADEMARKS.md`](TRADEMARKS.md). |
| Contribute a change | Read [`CONTRIBUTING.md`](CONTRIBUTING.md) first. |

## Before you post

Issues are public. Do not include credentials, tokens, serial numbers,
personal data, device or manual screenshots, copyrighted media, or proprietary
presets and captures. Describe behavior in text, with the minimum needed to
reproduce it. Everyone taking part is expected to follow the
[code of conduct](CODE_OF_CONDUCT.md).
