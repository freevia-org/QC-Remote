# QC Remote third-party source availability

QC Remote distributes unmodified executable forms of the components below under the indicated copyleft license. The exact corresponding source version can be downloaded from the versioned archive link shown. The complete applicable license text is included in `THIRD_PARTY-LICENSE-TEXTS.txt`.

If an archive link becomes unavailable, request the exact corresponding source for that distributed version by opening an issue at https://github.com/freevia-org/QC-Remote/issues or by email to security@freevia.org.

Selection rule: this list covers every component of `THIRD_PARTY-LICENSE-INVENTORY.json` - the components compiled into or bundled with the Windows app, the device broker and the Android app - whose license, or the license QC Remote selected where a component offers a choice, is MPL-2.0 or a GPL-family license. Development tooling that only builds, tests or deploys QC Remote (for example the LGPL-licensed image tooling some build tools use) is not distributed with QC Remote and carries no source offer; `THIRD_PARTY-NOTICES.md` lists it separately under "Development tooling (not distributed)".
