# Public reference data

This directory contains compact compatibility records consumed by the public
protocol checks. They describe the message-type table and the implementation's
supported, rejected, and currently unhandled message families.

Application builds do not require screenshots, product artwork, user data, or
other external evidence. Those materials are not included here and must not be
added to application packages or CI artifacts.

Run `npm run contracts:check` from the public repository root to check value-level
agreement of the Rust, Java, TypeScript and cloud snapshots, including message
types, colours, deadlines and positional gateway signatures. The private
maintainer generators and reference specifications remain private; this check
does not need them or publish them. Proposed changes should update the public
contract and be regenerated by the maintainer before integration.
